Method and limits

How the numbers were made, and what they cannot tell you.

The rules the build enforces

Every value traces to a source
The cost engine reads only parameters.json, and every parameter names a source id. The verifier fails if an id is unknown or a value has no source.
A blank is never a zero
Unknown values render as an em dash and carry a flag id. The verifier fails on a zero in a cell whose parameter is null.
The arithmetic is recomputed, not read
verify.py recomputes every ladder cell from the raw parameters and compares it to the published HTML.
Every table row carries a source link
Rows without an external source link fail the build, except inside a table explicitly marked as a flagged table, where the unverified marker takes its place. Statements about this site itself are written as lists, not tables.
No prohibited procedure
Prohibited routes have no steps. Their pages contain the statutory range and a pointer to a lawful route.
The build is reproducible
Two consecutive builds produce byte-identical output; CI asserts a clean git diff after rebuilding.

The arithmetic

USD amount A. CNY required = A × selling rate / 100. FX margin = A × (ask − mid) / mid. Commission = min(max(0.001 × CNY, 50), 260) CNY, applied per remittance. Cable = 150 CNY per remittance. China-side total = margin + commission + cable. The optional full-amount charge is shown separately because it is a corporate price line and its use on a personal transfer is unverified.

Why the one-way margin and not the round trip

You convert once. The bank buys USD from you at its selling rate; the midpoint is the fair reference. The loss on that single step is (ask − mid)/mid = 0.2104% on this board. The 0.4199% figure that circulates is the round trip, i.e. converting to USD and back. Using it for a single conversion would double the FX line, so both numbers are printed and the one-way figure is used.

What was not done

  • No account was contacted, no rate was quoted, no funds were moved.
  • No personal tax result was computed, because the residency, the source of funds, the acquisition dates and the filing history are unknown.
  • No provider was asked for a live quote. The Wise route carries its verified cap and a blank fee.
  • No commentary source was used for any value, including the 2026 US excise tax item, which is flagged instead (F-22).
  • No earlier edition's file was edited, except the single handover line in Edition D's generator, which is logged.

Reading the status vocabulary

lawful
The rule text provides the route and names no approval beyond documentary review.
lawful with approval
The rule text provides the route and names an approval or registration step.
lawful, conditional
Lawful if a fact about you or the money is true. The fact is not assumed here.
unverified
Commonly described, but no official instrument retrieved this session confirms it. Not priced, not recommended.
prohibited
Named as prohibited or penalised in an instrument on the register. No procedure is given.
