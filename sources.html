What "verified" means here, precisely retrieved — the page was fetched with the research tool and the quoted text was read in this session. excerpt — the official-domain page appeared in search results with the operative text quoted, but the page itself was not fetched end-to-end. unverified — no official URL could be confirmed; the claim is never used as a basis for a table value.

Live HTTP link-checking was not possible from the build environment: outbound access to the cited government hosts is blocked (only package registries are reachable), so curl returns 000 for every one of them. Rejected sources

Appearing in the registry as unverified is deliberate, not an oversight. These are listed so you can see exactly what was considered and excluded — and so a later reader cannot mistake their absence for ignorance of them.

Specifically excluded Commercial tax-consultancy reprints of Chinese circulars (used only as pointers to find the official text, never as the citation); blog posts quoting a precise FX spread; and any source asserting a "conversion tax" percentage without naming an instrument. Six specific values that are widely published are nonetheless left blank on this site because no official source fixes them — see Flagged for review.
Official text wins. If anything on this site conflicts with the instrument it cites, the instrument prevails.
