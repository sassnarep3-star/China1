Method

How this was researched, and where it stops

The interesting part of a source-verified document is not the sources — it is the record of what could not be verified and how that was handled.

What counted as a source

Only primary instruments: statutes, regulator-issued measures and notices, official gazette publications, and regulator Q&A on regulator domains. Specifically:

  • China: the State Council Gazette on gov.cn, SAFE and its regional sub-bureaus on safe.gov.cn, the People's Bank of China on pbc.gov.cn, and the State Taxation Administration on chinatax.gov.cn.
  • United States: the U.S. Code, the eCFR, and irs.gov / fincen.gov.
  • Never as the citation: law-firm marketing pages, tax-consultancy reprints, forums, or blogs. Those were used only as pointers to locate the official text, which was then read.

Three verification states, shown honestly

retrieved

The page was fetched during preparation and the quoted text was read directly.

excerpt

An official-domain page confirmed in search results with the operative text quoted, but not fetched end-to-end. Weaker than retrieved, and labelled as such.

unverified

No official page could be confirmed. Never used to fill a table value. Listed on the Flagged page.

The blank-value rule

A value is stated only if an official source fixes it. Everything else is left blank and flagged, with a note on what is missing and what would change if it were resolved. Seven items are blank or withheld on this site for exactly this reason — including two that would make the analysis read far more confidently if they were invented.

This rule is enforced mechanically, not by good intentions: the build script fails if any cost row marked unverified carries a value, or if any row marked verified cites no source. Try to publish a fabricated number and the build stops.

Two corrections made during research

R01 · The crypto rule everyone cites was repealed

My first pass captured 银发〔2021〕237号 as the operative Chinese crypto prohibition. It had been repealed on 2026-02-06 by 银发〔2026〕42号. The corrected analysis uses the current instrument and flags the staleness, because most search results still present the 2021 notice as law.

R02 · A legal database says the 2020 Guidelines are repealed. They aren't.

An aggregated database marks 汇发〔2020〕14号 as "wholly repealed". Cross-checking against 汇发〔2025〕13号's actual repeal list and SAFE's own pages showed the label is a scraping artefact. If I had trusted it, the entire Chinese half of this analysis would have collapsed into "no rule found".

Both are recorded on the Flagged page with sources. Recording a corrected error is more useful than quietly deleting it, because the error is one you are likely to encounter too.

What could not be checked, and why

The build environment has no outbound network access to any of the cited government hosts — only package registries are reachable, so an automated checker returns 000 for every one of them. External pages were therefore retrieved one at a time through the research fetch tool and read.

Consequence, stated plainly: link validity was established by fetch, not by an automated link checker. The build script validates URL syntax, that every cited source ID resolves, and that every internal link points at a real file — it cannot make a live HTTP request. Saying otherwise would be precisely the fabrication this project exists to avoid.

Scope limits you should hold me to

  • 21 channels are inventoried, including those that do not work. That is as complete as the rules reviewed allow — not a claim that no other lawful mechanism exists anywhere in Chinese law.
  • No cost total is given, because the two largest inputs are commercially set and published nowhere officially.
  • No treaty benefit and no foreign tax credit amount is asserted. Neither instrument was retrieved in this session, so neither is relied on.
  • Not advice. This is a research record. It is not legal, tax or investment advice, and it creates no adviser relationship.

Reproducing this

The whole project is plain files in the repository: data/*.json for every row and every source, research/*.md for the narrative and the line-by-line verification log, and scripts/build_site.py to regenerate assets/data.js and run the checks. Run python3 scripts/build_site.py to reproduce the validation output. Every factual claim has an ID you can trace: channels are C01–C21, cost components K1–K18, US forms U1–U6, prohibited routes P01–P06, flags F01–F07 and R01–R07, sources S01–S33.

If anything here conflicts with the instrument it cites, the instrument prevails. Chinese instruments are given by original title and document number so they can be located independently. Verify before relying on any figure.
