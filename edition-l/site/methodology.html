Method, constants and limits

Everything numeric on this site is produced by one Python script from two JSON data files. The script is deterministic: running it twice produces byte-identical pages. A separate verifier recomputes every cell independently and fails the build on any mismatch.

How this was verified

  1. Source-by-source retrieval. Each of the 21 documents was fetched on 2026-11-10 and the specific provision noted in the Sources table was read. Figures were taken from the fetched text, not from memory.
  2. Deterministic build. python3 edition-l/build/build.py regenerates eleven pages plus costs.json and costs.csv; a second run produces identical bytes.
  3. Independent recomputation. python3 edition-l/build/verify.py re-derives every commission, cable charge, spread, percentage and split total with its own Decimal arithmetic and refuses to pass if any published cell differs.
  4. Citation per row. The verifier parses every generated page and requires at least one HTTPS link to a government or first-party provider host in every data row; it also rejects a blank cell that carries a numeric value and a zero that represents an unknown.
  5. Link integrity. Every local href and every in-page anchor in this edition is resolved against the file system; external links must be HTTPS and on the documented host list.
  6. Non-regression. The pre-existing repository verifiers were run before and after integration and must still pass (see the coordination record).

Limits a reader must respect

  • A known total is not a quote. It excludes the intermediary deduction, any tax on the money's source, documentation costs and the rate you will actually be given.
  • Provider prices are as published on 2026-11-10 and can change; the documents are linked so the price can be re-checked.
  • Personal eligibility is not determined. See F01 and F22.
  • No live rate is displayed; the board figure is a timestamped observation and BOC itself says the executed rate governs (S12).
  • This is research, not legal, tax, investment or immigration advice, and it is not a substitute for the handling bank's review.
