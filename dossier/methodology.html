How this was built

Verification method

The brief required line-by-line verification against official sources, with nothing inferred and nothing filled in. This page states exactly how that was done, and where the method has limits.

The rules this project followed

RuleHow it was applied
Every number has an official sourceEach value in the route, cost and tax tables is either quoted from a tier-A instrument (or a tier-C institution for that institution's own quote) and linked, or independently derived by arithmetic on a quoted value and labelled "derived".
Nothing is inferredWhere a rule could not be read directly, the cell says "blank (unverified)" and the item appears on the Flagged page. There is no midpoint, range, "typically" or "around" anywhere in a numeric cell.
Quotation over paraphraseThe source registry stores the operative Chinese text (article and clause) alongside the link, so a reader can check the sentence rather than trust a summary. The Chinese is kept in the original because translation changes meaning in this field.
Three-tier source gradingTier A: the instrument or the issuing authority's own page. Tier B: an official republication of the instrument. Tier C: a regulated institution's own data. Nothing below tier C is used for a factual claim.
Negative findings stated as such"There is no Chinese exit tax" is recorded as a negative finding from the charging provisions of the IIT Law, not as proof that no administrative practice exists anywhere. It is marked PARTIAL for that reason.
Unlawful routes included and labelledDocumenting a prohibited route with its statutory penalty is not advice to use it. Omitting them would leave the reader unable to recognise the option they are about to be offered.

Reproducibility

All content lives in Python data modules under scripts/, and the pages are generated from them by scripts/build_site.py. The generator refuses to build if a table row cites a source id that does not exist, or if two rows share an id. The same data is exported to data/*.json so the tables can be re-used without scraping the HTML.

The build also runs an internal link check across every generated page and fails on any internal href that does not resolve to a file that exists.

Known limits of the method

Dynamic values

The FX spread is a live quotation. It was captured on 2026-11-08 from Bank of China's published board and will move daily. The structure of the cost is stable; the number is a snapshot. The page states the capture time so the snapshot can be re-checked.

Bank practice

Regulation and bank practice diverge in this field, in both directions. The dossier analyses the rule text and flags the divergence rather than pretending to know what a particular branch will do. See F16.

Untranslated instruments

The PRC instruments are not officially translated. Key clauses are reproduced in Chinese so they can be checked against the linked page rather than against this site's paraphrase.

Not advice

Application to a specific person requires a PRC-qualified lawyer and a US CPA or tax attorney. Cross-border work of this kind is routinely done by a pair. See F19.

Currency of the law

The framework instruments in use are: PBOC Order No. 3 [2006], 汇发[2007]1号, 汇发[2020]14号, PBOC Announcement [2004] No. 16, State Council Order No. 532, 国家税务总局/外汇局公告2013年第40号, and the 2018 IIT Law. SAFE FAQ pages dated 2026 confirm the 2020 guidance is still the operative reading.

What would change the answer

Three facts: how the bank classifies the account holder, where the money came from, and whether the US filings are current. The dossier is built so that each of those forks is visible rather than buried.
