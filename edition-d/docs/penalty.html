Decomposing the 'conversion penalty'

There is no single verified penalty. These are distinct layers; statutory penalty ceilings are not added to ordinary transfer costs.

L1 · FX quote / spread

Difference between the executable CNY-to-USD rate and a reference rate, plus any provider margin.

Verified: BOC indicative board observed: bid 666.48 / ask 669.29 / reference 671.68 per USD100. Round-trip bid/ask gap ≈0.42%; ask was below reference, so this does not prove a one-way loss.

L2 · Sender commission and cable/postage

Published bank or provider charges to send the money.

Verified: BOC TT: 0.1% min CNY50/max CNY260 + CNY150 cable. HSBC Premier/Advance: 0.1% min100/max500 + CNY120 cable; private-banking individual commission/cable free. HSBC Global Transfer Advance actual USD20/transfer; PB/Premier free.

Intermediary and receiving-bank deductions, cash deposit/collection fees, ATM surcharges.
