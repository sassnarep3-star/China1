What "line by line" means here. A script read every line of every archived text file and tested it against 12 rules. Each rule states a fact confirmed on an official page. A matching line is marked "consistent" when its own wording already agrees with the fact, otherwise "to check". The marking is a text heuristic, not a legal judgment; the full list with file and line number is in scan-hits.csv. Snapshot taken at commit f77b530.

Process irregularities

  • Pull requests #39 (conflicting) and #45 (mergeable) were still open when this session started. They are left open and are not merged by this session.
  • Claims by sessions arena-fc438b1a and arena-4207cf2f in COORDINATION.md were older than 60 minutes with no commits; their tasks were taken over as the protocol allows and the handoff is noted there.
  • While this session held the final-integration claim, Editions K and L each edited shared files (integration/build.py, the root portal, README.md and EXECUTIVE_SUMMARY.md) to register themselves. Resolved without loss: their links live on in legacy-portal.html and the Archive page, and their summary text is kept verbatim in guide/archive/.
  • Two sessions claimed the same folder name (edition-m) within two minutes of each other; one moved to edition-abd04d5f. Noted by that session and repeated here.
  • Fifteen parallel editions and components repeat the same research with different numbers. They are kept in place and linked only from the Archive page.
  • Independent cross-check: Editions K, L and abd04d5f, built in parallel from the same Bank of China board and tariff, reach the same wire arithmetic as this guide. They express the FX margin against the midpoint (0.2099%) where this guide expresses it against the selling rate (0.2094%), and they leave full-amount delivery out of the total.
  • Archived pages are not re-verified by this session beyond the rule scan below and their own build scripts, which all pass.
