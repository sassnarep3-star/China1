# Edition E research record

Report date: **2026-11-08 UTC**. This directory preserves the claim-level evidence used by `../data/` and the generated site. It is not a mirror of every web page.

## Method

1. Read the inherited requirements and prior editions without editing them.
2. Prefer the issuing regulator/government text. Where a commercial price is needed, use the provider’s own tariff/help page and label it `provider_primary`, never `government`.
3. Record the locator, the proposition supported, a short excerpt where available, retrieval mode and limitations in `../data/sources.json`.
4. Leave personal tax, executable FX, receiving-bank charges and unavailable product prices blank. Publish them on the flagged page.
5. Compute only transparent arithmetic from recorded inputs. A computed cell is a scenario, not a quote or a tax assessment.

## Files

- `source-notes.md`: human-readable evidence notes and corrections.
- `retrieval-log.md`: what was retrieved, what failed, and what remains excerpt-only.
- `arithmetic.md`: formulas and worked checks for the forty amount steps.
- `../data/sources.json`: canonical machine-readable register.
- `../audit.md`: inherited-edition adjudication.
